📋 Instrucciones

Crea un fichero JavaScript y vinculalo con tu fichero HTML.

  • Debes crear las variables: nombre, apellido, edad, pais y conocimientos, esta ultima debe ser un array.
  • Muestra todos los valores de las variables por la consola con una frase.
  • Después cambia el valor de la edad y añade un nuevo elemento al array.
  • Muestra esos nuevos valores por la consola.
